第 7 章 · Part 2：模型設定

Prompt Engineering 與 Tool Grounding

地端模型常見的工具幻覺問題與解法，包含 Tool Grounding 白名單、TERMINATION MANDATE 強制終止規則設計。

本章節內容已更新，請繼續閱讀。

Prompt Engineering 基礎

Prompt Engineering 是指設計和優化輸入給模型的提示（prompt），以獲得更好的輸出結果。良好的 Prompt Engineering 可以提高模型的準確性和可靠性。

💡

設計有效的 prompt 需要了解模型的特點和限制，並根據具體任務進行調整。

舊方法 vs 新方法：Prompt Engineering 的進化

方法 特點 優點 缺點
傳統 Prompt Engineering 依賴人工設計的 prompt 容易實現 需要大量的人工調試
現代 Prompt Engineering 結合自動化和優化技術 提高效率和準確性 需要額外的計算資源

Tool Grounding：解決工具幻覺問題

Tool Grounding 是一種技術，用於解決模型在使用工具時出現的幻覺問題。透過白名單機制和 TERMINATION MANDATE 規則，可以有效地減少模型的錯誤輸出。

⚠️

不當的 Tool Grounding 設定可能會導致模型無法正確使用工具，請謹慎配置。

Tool Grounding 白名單

白名單機制允許模型使用特定的工具或功能，減少幻覺問題的發生。

const whitelist = ['tool1', 'tool2'];

在上述範例中，我們定義了一個包含 'tool1' 和 'tool2' 的白名單。

TERMINATION MANDATE 強制終止規則

TERMINATION MANDATE 是一種強制終止規則，用於在特定條件下終止模型的輸出。

const terminationMandate = {
  condition: 'output.length > 100',
  action: 'terminate'
};

在上述範例中，我們定義了一個當輸出長度超過 100 時終止模型的規則。

最佳實踐

  • 根據具體任務設計有效的 prompt。
  • 使用白名單機制和 TERMINATION MANDATE 規則減少幻覺問題。
  • 持續監控和優化模型的輸出結果。
ℹ️

更多關於 Prompt Engineering 和 Tool Grounding 的資訊，請參考相關文獻和研究。

疑難排解

模型輸出不準確

檢查 prompt 是否設計得當，並嘗試優化。

模型出現幻覺問題

檢查 Tool Grounding 設定是否正確，並調整白名單和 TERMINATION MANDATE 規則。
